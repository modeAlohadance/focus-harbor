# FocusHarbor

Таймер рабочих сессий с паузами, перерывами и журналом завершённых задач.

Приложение для Windows с русским интерфейсом, работающее локально без аккаунта и сети.

## Возможности

- Длительность работы и перерыва настраивается.
- Пауза, продолжение и сброс таймера.
- Название задачи и история завершённых рабочих сессий.
- Суммарное время фокусировки за сегодня и экспорт журнала в CSV.
- После завершения работы предлагается перерыв; запуск следующего этапа вручную.

## Запуск

Скачайте `FocusHarbor.exe` из [Releases](https://github.com/modeAlohadance/focus-harbor/releases/latest).
Распаковывать или устанавливать Python для EXE не нужно. Сборка не подписана цифровым сертификатом.

Из исходников: Python 3.10+ с Tcl/Tk, затем `py -3 app.py` или двойной щелчок по `run.bat`.
Для обычного запуска внешние Python-библиотеки не требуются.

## Разработка

```powershell
python -m unittest discover -s tests -v
python app.py --smoke
```

`--smoke` создаёт интерфейс с временным хранилищем и закрывает его; пользовательские данные не меняются.
Для сборки EXE запустите `build.bat`: он создаст локальное виртуальное окружение и установит PyInstaller.
Результат появится в `dist/`. EXE собран для Windows x64.

## Устройство

`core.py`: таймер на монотонных часах и журнал SQLite. `app.py`: интерфейс Tkinter.
Данные: `%LOCALAPPDATA%/FocusHarbor/data.sqlite3`. Сохраняются только завершённые рабочие сессии.
Активный таймер не восстанавливается после закрытия. Сон компьютера может учитываться системными часами по-разному; перед сном ставьте таймер на паузу.
